# KrishiAtlas & KrishiGrantha — Architectural and Technical Decisions

This document records the architectural, engineering, and editorial decisions made for **KrishiAtlas** (the public web encyclopedia) and **KrishiGrantha** (the comprehensive concatenated agricultural reference book).

---

## 1. Technical Architecture & Static Generation

### Decision: Astro v7 with Pure Markdown Content Layer and Vanilla CSS
- **Context:** The project requires hosting 1,080+ in-depth, long-form articles, structured registers (subsidies, taxes, learning opportunities, land markets, state profiles), global full-text search, and automated book compilation. Hosting must be 100% free, reproducible, and zero-maintenance on GitHub Pages with zero external paid APIs, no tracking cookies, and no runtime server dependencies.
- **Alternatives Considered:**
  - *Next.js SSG:* Heavier client bundle, Node runtime assumptions, prone to build memory bloat with 1,000+ dynamic routes.
  - *Vite + React SPA:* Slower initial SEO indexation, lacks native markdown content collections and clean static HTML outputs for web crawlers.
  - *Astro:* Delivers zero-JS static HTML by default, exceptional build speed, native Markdown processing, accessible component model, and seamless GitHub Pages deployment.
- **Choice:** Astro v7 (static export mode) with pure TypeScript, accessible Vanilla CSS custom properties (warm agriscience dark/light mode palette), Web Speech API for TTS narration, and client-side deterministic search indexing.

---

## 2. Content Canonicalization & File Organization

### Decision: Individual Canonical Markdown Files Under `content/articles/`
- **File Naming & IDs:** Each article has an immutable ID `KA-001` through `KA-1080` and a descriptive slug: `content/articles/KA-001-what-agriculture-includes-and-where-its-boundaries-lie.md`.
- **Frontmatter Standard:** Every article contains validated YAML frontmatter including `id`, `title`, `part`, `part_title`, `slug`, `status`, `primary_topics`, `region_scope`, `crops_or_enterprises`, `source_ids`, `first_researched`, `last_verified`, `review_due`, `evidence_grade`, `related_article_ids`, `canonical_concepts`, and `book_include: true`.
- **Single Source of Truth:** `exports/KrishiGrantha_Master.md` is strictly generated by `scripts/build_book.py` from these canonical source files. No manual edits are ever permitted in the master export.

## 4. Rigorous Evidence, Financial Modeling & Uncertainty

### Decision: Full Separation of Gross Revenue vs. Risk-Adjusted Economic Profit
- **Policy:** Never claim generic, unsourced annual profits per acre. All crop models must account for establishment periods, fixed vs. variable costs, family labour valuation, land opportunity costs, crop cycle duration, working capital financing, water risk, pest gluts, market price volatility, and rejection rates.
- **Subsidy Baseline:** Always calculate the non-subsidized economic baseline first. Subsidy scenarios are presented as secondary variants with strict eligibility and fund availability caveats.

---

## 5. Owner Case Study Boundary & Ethical Publication

### Decision: Prominently Published with Clear Uncertainty Labels
- **Context:** The owner has explicitly authorized public case analysis regarding family land in Ghaziabad, UP, and career decision-making against TCS Bhubaneswar compensation (₹3.6 LPA package).
- **Security & Privacy Boundary:**
  - Published at `content/case-studies/owner-agriculture-vs-tcs.md` and integrated into Part 90 of both KrishiAtlas and KrishiGrantha.
  - Distinguishes owner-reported statements from verified cadastral and economic data.
  - No personal names or exact survey/khasra numbers are invented.
  - No private API keys, credentials, machine paths, or confidential corporate data are included.
